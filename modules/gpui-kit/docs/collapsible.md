The kit's `Collapsible`, written by hand on the same specification as the generated components. The React Native side is in `src/manual`.

## Native props

| Name   | Type      |
| ------ | --------- |
| `open` | `boolean` |

## Coverage

- `Collapsible::new`: generated, constructor
- `Collapsible::open`: generated (open)
- `Collapsible::motion_id`: generated, the node id; the reveal animates unless animations are disabled
- `Collapsible::content`: generated, the content slot (React children)
- `Collapsible::child`: generated, the trigger slot
